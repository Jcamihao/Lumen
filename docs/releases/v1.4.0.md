# LUMEN 1.4.0

Data: `2026-04-27`

## Resumo

A versão 1.4.0 melhora o fluxo de importação financeira, deixando o processamento de arquivos mais rastreável e a experiência no dashboard mais clara.

## Entregas principais

- serviço de importações com retorno mais detalhado sobre itens processados
- novos contratos de domínio para resumo e histórico de importação
- tela de importações com resumo visual, estados de processamento e mensagens de validação
- dashboard atualizado para refletir melhor os dados importados
- sidebar simplificada para manter foco no workspace principal

## Impacto esperado

- diagnóstico mais rápido de problemas em arquivos CSV
- menos ambiguidade depois de uma importação concluída
- leitura mais clara do impacto financeiro no dashboard
- navegação lateral mais objetiva
