# Release Notes - v1.16.0 (Lumen)

Tag criada na `develop` em 2026-11-24 pela regra de tags por task. Marca o fechamento do **item 10: bot do Telegram** (10a backend + 10b cartão no app + 10c integração real no navegador). Contrato: `docs/superpowers/specs/2026-11-23-conversa-contrato-item-10.md` (D1–D8 **assumidos pela sessão** por delegação do dono — foi a primeira vez que o contrato nasceu da própria sessão, documentado como assumido).

## O que o Lumen passou a fazer
- **Canal Telegram completo:** a pessoa vincula um chat do Telegram à conta pelo **código de vínculo de 8 caracteres** (mesmo desenho do WhatsApp do 5b: só o hash vai ao banco, validade 10 min, um uso) e conversa com o bot: "50 mercado", "saldo", "gastos por categoria", editar/apagar, tudo pelo MESMO motor do assistente, com o teclado de resposta `confirmar/cancelar` (botões de texto do Telegram, anexados só à última parte da resposta).
- **Sem webhook, sem host público:** o backend consome a Bot API por **long polling** (`getUpdates`) com o offset persistido por update lido — restart não perde nem repete nada. **Caveat: exatamente UMA instância do backend pode rodar com `TELEGRAM_ENABLED=true`** (o polling não divide updates; registrado no contrato D2).
- **Trava de escrita (D3):** `TELEGRAM_WRITES_ENABLED=false` por padrão — pelo chat o bot monta rascunho e responde consultas, e o "confirmar" pede o app; o app continua gravando normalmente e passou a **ver e confirmar o rascunho aberto pelo Telegram** (D9 estendido).
- **Privacidade (D1/D7):** o `chat.id` inteiro nunca sai do banco — status e logs mostram `98••••••10`; o dono da sessão vem só do vínculo; sem Redis o canal desconhecido fica mudo (falha fechada); limites por chat iguais aos do WhatsApp (20 msgs/min, 5 códigos errados/10 min, 1 orientação/h).
- **Mídia (D5):** foto/arquivo pelo chat recebe a orientação de usar a tela de Importações. Texto acima de 1000 caracteres é recusado curto.
- **App:** cartão **"Telegram" em Configurações > Conta** (ao lado do WhatsApp) com os estados desligado/sem vínculo/código com prazo/vinculado mascarado, copiar, expiração, detecção automática do vínculo e desvincular em duas etapas.
- Sem dependência nova (Bot API por fetch cru, D8 — a base da API é configurável, o que permitiu testar contra Bot API falsa).

## Antes de ligar em produção (ação do dono)
1. Criar o bot no @BotFather e anotar o token; **nunca testado contra `api.telegram.org`** — validar com o bot real antes de divulgar.
2. No servidor: `TELEGRAM_BOT_TOKEN=...`, `TELEGRAM_ENABLED=true` (depois `TELEGRAM_WRITES_ENABLED=true`, quando quiser escrita pelo chat — idealmente depois da validação real).
3. Garantia de **instância única** do backend com o canal ligado.
4. O número de produção do WhatsApp (5d) segue pendente e independe deste item.
