# LUMEN 1.3.0

Data: `2026-04-08`

## Resumo

A versão 1.3.0 reforça a operação mobile do LUMEN com bootstrap mais estável, navegação autenticada com transições suaves e melhor compatibilidade entre web e Capacitor.

## Entregas principais

- backend com suporte explícito a `HOST`, facilitando deploy em ambientes gerenciados
- service worker desativado em runtime nativo para evitar conflitos com Capacitor
- hidratação de storage local com timeout defensivo e trilha de debug no boot
- refresh de sessão com tempo limite para evitar telas presas em redes instáveis
- animação de transição entre páginas do workspace e redirecionamento inicial consistente para login

## Impacto esperado

- menos risco de travamento na abertura do app mobile
- recuperação mais rápida quando a sessão expira ou a rede oscila
- experiência de navegação mais polida no shell autenticado
- deploy mais previsível em containers e plataformas com binding por host
