# Release Notes - v1.11.0 (Lumen)

Tag criada na `develop` em 2026-11-23 pela regra de tags por task. Marca o fechamento do **item 8a: editar e apagar lançamento por conversa** (backend 8a-1 + app 8a-2 + ajustes das decisões do dono).

## O que o bot passou a fazer
- "apagar <termo>" e "editar <termo>" localizam o lançamento do dono (um alvo → rascunho direto; vários → lista numerada para escolher, inclusive em sessão reaberta).
- O rascunho de **apagar** só grava com a ação explícita: a palavra `apagar` no chat ou o botão **"Apagar de vez"**, que manda `delete: true` **literal** no REST (string não vale — o pipe global usa `enableImplicitConversion`). "confirmar/sim/ok" não apagam.
- O de **editar** mostra antes→depois nas linhas do cartão; RESTORED traz o `changeAction` para o app pintar o botão certo depois de F5.
- Ajustes decididos pelo dono: o apagar confere `updatedAt` sob lock (tela mexeu no meio → conflito com o estado atual, sem gravar) e transferência (`TRANSFER`) ficou fora do editar/apagar.
